This Page Uses Jekyll Templates

This is an example page showing how Jekyll templates work. Notice how this file is much shorter than the regular HTML files - it only contains the content, not the navigation, footer, or repeated styles.

This file starts with:

---
layout: default
title: example page
custom_css: |
  /* Page-specific styles */
---

<section>
  Your content here
</section>

The navigation and footer are automatically included from the template files in _includes/

To make your own pages use this system:

  1. Add the front matter (the --- section) to the top of your HTML file
  2. Remove the <head>, <nav>, and <footer> sections
  3. Keep only the main content
  4. Add page-specific CSS in the custom_css section
